# Veritas repository instructions

- Treat each implementation phase as a hard gate.
- Do not mark a phase complete until its verification command passes.
- Do not hard-code claim-to-artifact relationships in UI or runtime code; registered relationships must come from a Claim Manifest.
- Do not claim universal truth. Veritas certifies consistency only for monitored claims and registered evidence versions.
- Recorded demo paths must use real Google Workspace APIs and Google Cloud services.
- Preserve unrelated user edits and unrelated files.
