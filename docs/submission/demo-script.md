## 0:18–0:36 — Product promise

**Screen:** Veritas opening view.

**Say:** “When source truth changes, Veritas repairs every registered consequence—and proves the result. It records claim-level provenance, watches the evidence, preserves human authorship, and independently verifies the repair.”

**Screen:** Google Sheets. Change churn from 4% to 9% and press Enter. Do not touch Veritas.

**Say:** “I’ll change the real source from four to nine percent. From this point, there is no prompt and no hand-holding.”

## 0:58–1:20 — Autonomous detection

**Screen:** Veritas timeline updates.

**Say:** “The authenticated Drive event is deduplicated. Veritas refetches the exact range, seals an immutable snapshot, rejects cosmetic noise, and opens an incident only for a meaningful change.”

## 1:20–1:45 — Exact blast radius

**Screen:** Blast Radius.

**Say:** “This is not a similarity search. The versioned Claim Manifest traces exactly four affected claims through nine registered paths into five artifacts. Four unrelated claims remain untouched, and inferred candidate edges cannot authorize a repair.”

**Screen:** Live Run → Gemini Safety Decision receipt, then Repair Desk; approve the two decision-changing claims.

**Say:** “Gemini reviews the semantic change and exactly these four registered claims. Its schema-bound decision is proceed, with decision-changing claims flagged for human authority. It cannot add scope, approve itself, or issue a certificate. Facts can repair automatically; recommendations pause for me, and sent email remains immutable.”

## 2:08–2:45 — Native cross-artifact repair

**Screen:** Timeline, then rapidly inspect Docs, Slides, Gmail drafts, and Tasks.

**Say:** “The worker patches registered named ranges, registered slide shapes, and the task note using native revision preconditions. It creates correction drafts instead of rewriting history. Every step is journaled, so an interrupted worker resumes without repeating completed writes.”

## 2:45–3:05 — Preserve the human

**Screen:** Board memo paragraph written by the CFO before the change.

**Say:** “This paragraph was never generated or registered by Veritas. Its protected hash is unchanged. If a collaborator edits the same claim anchor, Veritas produces a conflict—not an overwrite.”

**Screen:** Verification view.

**Say:** “The repair agent does not grade its own work. A separate read-only verifier reopens all thirteen registered targets, recomputes all eight monitored claims from six evidence versions, confirms both correction drafts, and proves all five protected regions survived.”

## 3:25–3:40 — Certificate

**Screen:** Certificate; briefly print/open it.

**Say:** “Only after all thirty-six checks pass does Veritas issue this scoped certificate: all monitored claims are consistent with these registered evidence versions. It never claims the whole document is universally true.”

**Say:** “The Q3 scenario is a versioned blueprint passed to the packet API—not hard-coded workflow logic. **Say:** “AI created the work. Veritas keeps it true.”
