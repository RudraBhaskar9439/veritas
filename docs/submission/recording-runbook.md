# Demo recording runbook

## One day before

- Deploy immutable API, ingress, worker, and web images from the accepted commit.
- Apply all SQL migrations and record the Cloud Run revisions and image digests.
- Use a dedicated demo Workspace account with only the required scopes.
- Generate a fresh canonical packet through the product; never reuse a pre-repaired packet.
- Add the CFO paragraph manually after packet generation.
- Confirm Drive and Gmail watches, authenticated Pub/Sub subscriptions, Cloud Tasks queue, snapshot bucket, KMS key, database, log metrics, and dead-letter alert are healthy.
- Run the real negative checks: formatting-only suppression, wrong repair rejection, duplicate event, worker interruption, and stale source.
- Run five complete timed rehearsals from fresh packets. Record duration, run ID, certificate ID, commit, and any intervention.

## Recording layout

- 1920×1080, browser zoom 100%, system notifications disabled.
- Keep one browser window with ordered tabs: customer Gmail, Sheet, Veritas Live Run, Memo, Deck, Gmail drafts, Task, Veritas Architecture, GitHub workflow.
- Keep the mouse still while speaking; use deliberate clicks and no rapid scrolling.
- Increase cursor size slightly and ensure every value is legible at 1080p.
- Record microphone and screen in one continuous take. Do not splice a failed run into a successful one.

## Sixty seconds before

- Confirm Sheet shows 4%, not 9%.
- Confirm Veritas shows no active incident.
- Confirm the CFO paragraph exists and capture its pre-run hash.
- Confirm Gmail contains the sent original and no correction draft for this run.
- Confirm the task and all registered anchors show the old claims.
- Confirm the external customer is allowlisted, the normal opening email is present, and its Gmail thread is bound to the manifest-provided Task.
- Confirm network, account, public URL, and health endpoints.
- Confirm **Live Run** exposes the seven-stage transaction ribbon and the persisted Gemini Safety Decision receipt.
- Confirm **Architecture** exposes the reusable Packet Contract panel and the current packet ID.
- Start a four-minute timer beside the recording controls, outside the captured region.

## After recording

- Do not claim success from the video alone.
- Save run IDs, snapshot generations, mutation receipts, protected hashes, verification report checksum, certificate ID, Cloud Run revisions, and GitHub workflow URL.
- Watch the final upload at 1× speed with captions enabled.
- Verify no OAuth token, project secret, personal email, billing identifier, or unredacted sensitive Workspace content is visible.
